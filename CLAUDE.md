# AI Video Studio — Règle permanente (obligatoire)

Avant d'exécuter toute tâche, analyser systématiquement, dans l'ordre :

1. Les outils déjà installés.
2. Les MCP (Model Context Protocol) disponibles.
3. Les API officielles.
4. Les SDK officiels.
5. Les extensions disponibles.
6. Les automatisations existantes.

Si une solution gratuite, officielle ou open source permet de réaliser la tâche : l'utiliser en priorité, l'installer et la configurer si nécessaire, éviter de réinventer une solution existante.

Si plusieurs solutions gratuites existent : choisir la plus stable, la plus maintenue, la plus adaptée à AI VIDEO STUDIO.

Si une solution nécessite un abonnement, un achat ou un service payant : **ne rien installer**. Afficher obligatoirement ces trois alertes, puis attendre la réponse de l'utilisateur avant toute action :

- ⚠️ SOLUTION PAYANTE DÉTECTÉE
- ⚠️ AUTORISATION UTILISATEUR OBLIGATOIRE
- ⚠️ AUCUNE ACTION EFFECTUÉE SANS VALIDATION
